# (LV) Merjenje hitrosti

Ali se avtomobilček giblje enakomerno — in kako hitro?

<p class="tiho">1. letnik · Opis premega gibanja · ura 16</p>

<Opombe>
Cilj vaje: izmerimo lego avtomobilčka ob več časih, narišemo graf x(t), iz oblike grafa presodimo, ali je gibanje enakomerno, in iz strmine določimo hitrost z napako.

Navezava: graf in strmina iz ur 8 in 9, povprečje in napaka iz ur 6 in 7, graf x(t) in strmina kot hitrost iz ure 15.

Pripomočki na skupino (4 dijaki): avtomobilček na baterije, merilni trak ali lepilni trak z oznakami na tleh, štoparice na telefonih, karo papir in ravnilo.
</Opombe>

<div class="ozko">

<Kljucno naslov="Raziskovalno vprašanje">

Ali se avtomobilček giblje **enakomerno**? Kolikšna je njegova **hitrost**?

</Kljucno>

</div>

<Opombe>
Avtomobilček zaženemo pol metra pred oznako 0 — v zaletu doseže stalno hitrost. Čas začnemo meriti, ko prečka oznako 0; tam je izhodišče in tam je t = 0.

Vprašam: kako bomo iz izmerkov vedeli, ali je gibanje enakomerno? Pričakovani odgovor: točke na grafu x(t) ležijo na premici.
</Opombe>

---

## Kako merimo

<div class="postopek">

1. Avtomobilček zaženemo pred oznako 0. Ko prečka **oznako 0**, vsi hkrati vklopijo štoparico.

2. Vsak izklopi štoparico, ko avtomobilček prečka **njegovo oznako**.

3. Vožnjo **trikrat ponovimo**; dijaki se zamenjajo, da ima vsaka oznaka tri izmerke.

4. Izmerke vpisujemo v preglednico — z enotami v glavi.

</div>

<div class="ozko">

<Kljucno>

Merimo **čas do vsake oznake**, ne čas med sosednjima oznakama.

</Kljucno>

</div>

<Opombe>
Organizacija: štirje dijaki pri štirih oznakah, nato se premaknejo. Šest oznak × tri izmerki = 18 izmerkov; pri štirih dijakih to pomeni pet voženj.

Na oznako 0 da znak eden od dijakov (»zdaj«) — tako je zamik vklopa pri vseh podoben.
</Opombe>

## Preglednica izmerkov

<div class="tabela-izmerkov tabela-izmerkov--polna">

| $x$ [m] | $t_1$ [s] | $t_2$ [s] | $t_3$ [s] | $\bar{t}$ [s] | $\Delta t$ [s] |
|---:|---:|---:|---:|---:|---:|
| 0,50 | 1,24 | 1,38 | 1,31 | 1,3 | 0,1 |
| 1,00 | | | | | |
| 1,50 | | | | | |
| 2,00 | | | | | |
| 2,50 | | | | | |
| 3,00 | | | | | |

</div>

$\bar{t} = \dfrac{t_1 + t_2 + t_3}{3} = \dfrac{1{,}24\ \text{s} + 1{,}38\ \text{s} + 1{,}31\ \text{s}}{3} = 1{,}3\ \text{s}$

$\Delta t = \dfrac{t_\text{max} - t_\text{min}}{2} = \dfrac{1{,}38\ \text{s} - 1{,}24\ \text{s}}{2} = 0{,}07\ \text{s} \approx 0{,}1\ \text{s}$

<Opombe>
Prva vrstica je zgled izračuna. Povprečje zapišemo na isto decimalko kot napako: napaka 0,07 s se zaokroži na 0,1 s, zato povprečje 1,3 s.

Napaka po pravilu razpona — kot v uri 6. Pri treh izmerkih pravila dveh tretjin ne uporabimo.
</Opombe>

## Obdelava izmerkov

<div class="stolpca stolpca--ozko-desno">

<div class="postopek">

1. **Graf** $x(t)$ — čas na os $x$, lego na os $y$; ob vsaki točki vodoravna daljica $\pm \Delta t$

2. **Premica**, ki se točkam najbolje prilega

3. **Enakomerno?** — točke ležijo na premici znotraj svojih napak

4. **Strmina** iz dveh točk na premici — to je hitrost $v$

5. **Napaka hitrosti** — iz zadnje oznake: relativni napaki $x$ in $\bar{t}$ seštejemo

</div>

<div>

<Temelj>

$$
v = \frac{x_2 - x_1}{t_2 - t_1}
$$

$$
\delta v = \delta x + \delta t
$$

</Temelj>

</div>

</div>

<Opombe>
Pri deljenju se relativni napaki seštejeta — ura 7. Napaka lege je pol razdelka traku ali širina oznake, okoli 1 cm.

Strmina je hitrost, ker je enota strmine m s⁻¹ — ura 15.
</Opombe>

## Kako je videti obdelan graf

  branja={[{ x: 2, y: 0.8 }, { x: 7, y: 2.9 }]}

<div>

<Vprasanje oznaka={false}>

Je gibanje enakomerno? Kolikšna je hitrost?

<Odgovor>

**Da** — točke ležijo na premici.

$v = \dfrac{x_2 - x_1}{t_2 - t_1} = \dfrac{2{,}9\ \text{m} - 0{,}8\ \text{m}}{7{,}0\ \text{s} - 2{,}0\ \text{s}}$

$\phantom{v} = 0{,}42\ \text{m}\,\text{s}^{-1}$

$\delta v = \delta x + \delta t = 0{,}003 + 0{,}014 \approx 0{,}02$

$v = 0{,}42\,(1 \pm 0{,}02)\ \text{m}\,\text{s}^{-1}$

</Odgovor>
</Vprasanje>

</div>

</div>

<Opombe>
Podatki so primer druge skupine z drugim avtomobilčkom — vsaka skupina dobi svojo hitrost.

Relativni napaki pri zadnji oznaki: δx = 0,01 m / 3,00 m = 0,003 in δt = 0,1 s / 7,3 s = 0,014.

Točki za strmino vzamemo s premice in daleč narazen, ne iz preglednice. Absolutna napaka: 0,02 · 0,42 m s⁻¹ ≈ 0,01 m s⁻¹, torej v = (0,42 ± 0,01) m s⁻¹.
</Opombe>

## Zakaj strmina in ne en sam izmerek?

<div>

<Vprasanje oznaka={false}>

Hitrost bi lahko izračunali tudi iz ene oznake: $v = x / \bar{t}$. Zakaj je strmina premice boljša?

<Odgovor>

Pri štoparici zamujamo za **odzivni čas**, okoli 0,2 s. Zamik premakne vse točke za isti čas: premica se premakne vstran, **strmina ostane enaka**. Pri $v = x / \bar{t}$ pa zamik ostane v rezultatu.

</Odgovor>
</Vprasanje>

</div>

<div class="ozko">

<Kljucno>

Iz **več točk** in **strmine** dobimo hitrost, na katero zamik pri merjenju časa ne vpliva.

</Kljucno>

</div>

<Opombe>
Zato premica ne gre nujno skozi izhodišče: v primeru z grafa seka os t pri približno 0,1 s.

Kdor želi preveriti: pri prvi oznaki 0,5 m / 1,3 s = 0,38 m s⁻¹, pri zadnji 3,0 m / 7,3 s = 0,41 m s⁻¹ — pri kratkem času je razlika večja.
</Opombe>

## Povzetek

- gibanje je enakomerno, če točke na grafu $x(t)$ ležijo **na premici**
- **strmina** grafa $x(t)$ je hitrost — dobimo jo iz dveh točk na premici
- napako hitrosti ocenimo s seštevanjem relativnih napak: $\delta v = \delta x + \delta t$
- zamik pri merjenju časa premakne premico, strmine pa ne spremeni
