# Utrjevanje: električna vezja

Nadomestni upor · tok in napetost na vsakem uporniku

<p class="tiho">3. letnik · Električni tok · ura 23</p>

<Opombe>
Cilj ure v enem stavku: znam v vezju upornikov izračunati nadomestni upor ter tok in napetost na vsakem uporniku.

Ura je v celoti utrjevanje — novih enačb ni. Na prosojnicah je štirinajst vezij. A–D so jedro ure: trije vzporedni uporniki, dva vzporedna para zaporedno, veja v veji in vezje s stikalom. Sledijo E–N, razvrščene od lažjih k težjim: E–G za ogrevanje ali šibkejši razred, H–K na ravni A–D, L–N za močnejše. Naloge v rubriki Naloge so drugačne in so za doma. Vsako nalogo dijaki najprej rešujejo sami, nato pokažem rešitev v istem zaporedju, kot ga zahtevam od njih: najprej podatki, nato postopek po receptu.

Časovnica: recept 0–4 · A 4–12 · B 12–22 · C 22–33 · D 33–45. Če zaostanemo, izpade naloga C, nikoli D. Kdor konča prej, nadaljuje z E–N; kar ostane, je za doma. Naloge lahko tudi zamenjam — npr. v šibkejšem razredu E–G namesto C.

Pripomočki: kalkulator, geotrikotnik.
</Opombe>

---

## Recept

<div class="stolpca stolpca--ozko-desno">

<div>

1. **Kaj je enako?** — zaporedno tok, vzporedno napetost.
2. **Del za delom** — vsak zaporedni ali vzporedni del nadomestimo z enim upornikom, od znotraj navzven.
3. **Tok iz vira** — $I = \dfrac{U}{R}$ za celo vezje.
4. **Nazaj po vezju** — napetost na vsakem delu, nato tokovi v vejah.
5. **Preverba** — vsota tokov v razvejišču, vsota napetosti po zanki.

</div>

<div>

<Kljucno naslov="Enačbe">

$$
U = R I
$$

$$
R = R_1 + R_2 + \dots
$$

$$
\frac{1}{R} = \frac{1}{R_1} + \frac{1}{R_2} + \dots
$$

</Kljucno>

</div>

</div>

<Opombe>
Recept zapišem na rob table in ga pustim do konca ure; pri vsaki rešitvi pokažem, v katerem koraku smo. Vezave veljajo za poljubno število upornikov — pri treh vzporednih se dijaki radi ustavijo pri obrazcu za dva (R₁R₂/(R₁ + R₂)).
</Opombe>

## Naloga A · rešitev

<div class="podatki">

- $U = 6{,}0\ \mathrm{V}$, $R_1 = 10\ \Omega$, $R_2 = 15\ \Omega$, $R_3 = 30\ \Omega$

</div>

<div class="postopek">

1. **Nadomestni upor** — $\dfrac{1}{R} = \dfrac{1}{R_1} + \dfrac{1}{R_2} + \dfrac{1}{R_3} = \dfrac{1}{10\ \Omega} + \dfrac{1}{15\ \Omega} + \dfrac{1}{30\ \Omega} = \dfrac{6}{30\ \Omega}$, &nbsp; $R = 5{,}0\ \Omega$

2. **Tokovi** — na vseh je napetost vira: $I_1 = \dfrac{U}{R_1} = \dfrac{6{,}0\ \mathrm{V}}{10\ \Omega} = 0{,}60\ \mathrm{A}$, &nbsp; $I_2 = 0{,}40\ \mathrm{A}$, &nbsp; $I_3 = 0{,}20\ \mathrm{A}$

3. **Iz vira** — $I = I_1 + I_2 + I_3 = 1{,}2\ \mathrm{A}$; &nbsp; preverba: $I = \dfrac{U}{R} = \dfrac{6{,}0\ \mathrm{V}}{5{,}0\ \Omega} = 1{,}2\ \mathrm{A}$

4. **Brez $R_3$** — tok skozi $R_1$ ostane $0{,}60\ \mathrm{A}$, ker je napetost na njem enaka; tok iz vira se zmanjša na $1{,}0\ \mathrm{A}$

</div>

<Opombe>
Pri 1 skupni imenovalec 30 Ω. Nadomestni upor 5,0 Ω je manjši od najmanjšega (10 Ω) — hitra preverba. Največji tok teče skozi najmanjši upor.
</Opombe>

## Naloga B · rešitev

<div class="podatki">

- $U = 12\ \mathrm{V}$, $R_1 = 6{,}0\ \Omega$, $R_2 = 3{,}0\ \Omega$, $R_3 = R_4 = 12\ \Omega$

</div>

<div class="postopek">

1. **Para** — $\dfrac{1}{R_{12}} = \dfrac{1}{R_1} + \dfrac{1}{R_2} = \dfrac{1}{6{,}0\ \Omega} + \dfrac{1}{3{,}0\ \Omega}$, &nbsp; $R_{12} = 2{,}0\ \Omega$; &nbsp; enaka upornika: $R_{34} = 6{,}0\ \Omega$

2. **Celota** — $R = R_{12} + R_{34} = 8{,}0\ \Omega$, &nbsp; $I = \dfrac{U}{R} = \dfrac{12\ \mathrm{V}}{8{,}0\ \Omega} = 1{,}5\ \mathrm{A}$

3. **Napetosti** — $U_{12} = I R_{12} = 1{,}5\ \mathrm{A} \cdot 2{,}0\ \Omega = 3{,}0\ \mathrm{V}$, &nbsp; $U_{34} = I R_{34} = 9{,}0\ \mathrm{V}$

4. **Tokovi** — $I_1 = \dfrac{U_{12}}{R_1} = 0{,}50\ \mathrm{A}$, &nbsp; $I_2 = 1{,}0\ \mathrm{A}$, &nbsp; $I_3 = I_4 = \dfrac{U_{34}}{R_3} = 0{,}75\ \mathrm{A}$

</div>

<Opombe>
Preverba: 3,0 V + 9,0 V = 12 V (zanka); 0,50 A + 1,0 A = 0,75 A + 0,75 A = 1,5 A (razvejišči). Večji del napetosti je na paru z večjim nadomestnim uporom.
</Opombe>

## Naloga C · rešitev

<div class="podatki">

- $U = 20\ \mathrm{V}$, $R_1 = 4{,}0\ \Omega$, $R_2 = 12\ \Omega$, $R_3 = 8{,}0\ \Omega$, $R_4 = 4{,}0\ \Omega$

</div>

<div class="postopek">

1. **Desna veja** — $R_{34} = R_3 + R_4 = 8{,}0\ \Omega + 4{,}0\ \Omega = 12\ \Omega$

2. **Vzporedni del** — $\dfrac{1}{R_\mathrm{v}} = \dfrac{1}{R_2} + \dfrac{1}{R_{34}} = \dfrac{1}{12\ \Omega} + \dfrac{1}{12\ \Omega}$, &nbsp; $R_\mathrm{v} = 6{,}0\ \Omega$; &nbsp; celota $R = R_1 + R_\mathrm{v} = 10\ \Omega$

3. **Skozi $R_1$** — $I = \dfrac{U}{R} = \dfrac{20\ \mathrm{V}}{10\ \Omega} = 2{,}0\ \mathrm{A}$, &nbsp; $U_1 = I R_1 = 2{,}0\ \mathrm{A} \cdot 4{,}0\ \Omega = 8{,}0\ \mathrm{V}$

4. **Vzporedni del** — $U_\mathrm{v} = U - U_1 = 12\ \mathrm{V}$; &nbsp; $I_2 = \dfrac{U_\mathrm{v}}{R_2} = 1{,}0\ \mathrm{A}$, &nbsp; $I_{34} = 1{,}0\ \mathrm{A}$, &nbsp; $U_4 = I_{34} R_4 = 4{,}0\ \mathrm{V}$

</div>

<Opombe>
Pogosta napaka pri 4: na vzporedni del vstavijo napetost vira 20 V — pred njim je R₁, na katerem je 8,0 V. Preverba: U₃ = 8,0 V, U₃ + U₄ = 12 V = U₂.
</Opombe>

## Naloga D · rešitev

<div class="podatki">

- $U = 12\ \mathrm{V}$, $R_1 = 4{,}0\ \Omega$, $R_2 = R_3 = 8{,}0\ \Omega$

</div>

<div class="postopek">

1. **Odprto** — skozi $R_3$ ne teče tok: $R = R_1 + R_2 = 12\ \Omega$, &nbsp; $I = \dfrac{U}{R} = 1{,}0\ \mathrm{A}$, &nbsp; $U_2 = I R_2 = 8{,}0\ \mathrm{V}$

2. **Sklenjeno** — enaka upornika vzporedno: $R_{23} = 4{,}0\ \Omega$; &nbsp; $R = R_1 + R_{23} = 8{,}0\ \Omega$, &nbsp; $I = \dfrac{U}{R} = 1{,}5\ \mathrm{A}$

3. **Napetost na $R_2$** — $U_1 = I R_1 = 6{,}0\ \mathrm{V}$, &nbsp; $U_2 = U - U_1 = 6{,}0\ \mathrm{V}$

4. **Tok skozi $R_2$** — $I_2 = \dfrac{U_2}{R_2} = 0{,}75\ \mathrm{A}$ — **zmanjša** se: tok iz vira se poveča, na $R_1$ je zato večja napetost in za $R_2$ ostane manj

</div>

<Opombe>
Sprememba v eni veji spremeni nadomestni upor, s tem tok iz vira in napetosti v celem vezju. Pri vzporedni vezavi neposredno na vir (naloga A) se to ne zgodi — tam je pred vejami le idealen vir.
</Opombe>

## Naloga L · rešitev

<div class="podatki">

- $U = 12\ \mathrm{V}$, $R_1 = R_4 = 2{,}0\ \Omega$, $R_2 = R_3 = 4{,}0\ \Omega$

</div>

<div class="postopek">

1. **Veji** — $R_{12} = R_1 + R_2 = 6{,}0\ \Omega$, &nbsp; $R_{34} = R_3 + R_4 = 6{,}0\ \Omega$; &nbsp; enaki veji vzporedno: $R = 3{,}0\ \Omega$

2. **Tokovi** — na vsaki veji je $U$: $I_{12} = \dfrac{U}{R_{12}} = \dfrac{12\ \mathrm{V}}{6{,}0\ \Omega} = 2{,}0\ \mathrm{A}$, &nbsp; $I_{34} = 2{,}0\ \mathrm{A}$, &nbsp; $I = 4{,}0\ \mathrm{A}$

3. **Napetosti** — $U_1 = I_{12} R_1 = 2{,}0\ \mathrm{A} \cdot 2{,}0\ \Omega = 4{,}0\ \mathrm{V}$, &nbsp; $U_3 = I_{34} R_3 = 2{,}0\ \mathrm{A} \cdot 4{,}0\ \Omega = 8{,}0\ \mathrm{V}$

<Opombe>
